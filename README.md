# UnityTemplateRepository
Unity Project template Repository

# Contents

This template currently contains only:

* `.gitignore` — the gitignore.io `unity,rider` template
* `LICENSE` — Apache License 2.0

It does not include a Unity project (`Assets/`, `Packages/`, `ProjectSettings/`).
After creating a repository from this template, create the Unity project at the repository root.

# requirements
* Unity 2022.2.0f1
